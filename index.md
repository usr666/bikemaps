# Bike maps

## How to add GPX files

_No GPX files found yet._

Add `.gpx` files to [`maps/`](./maps/) and list them below using this format (replace `USERNAME` with your GitHub user/org, `REPOSITORY` with your repo name, and `BRANCH` with your branch, e.g. `usr666`, `bikemaps`, `main`):

- [filename.gpx](https://gpx.studio/?state=%7B%22urls%22%3A%5B%22https%3A%2F%2Fraw.githubusercontent.com%2FUSERNAME%2FREPOSITORY%2FBRANCH%2Fmaps%2Ffilename.gpx%22%5D%7D)
